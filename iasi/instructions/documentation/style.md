# Documentation style

## Purpose

Define the baseline editorial style for documentation produced under iasi.

## Rules

- The agent MUST use the language established by the target document. If none is established, it SHOULD use Spanish.
- The agent SHOULD write clear, precise technical prose.
- The agent SHOULD prefer cohesive paragraphs over unnecessary enumeration.
- Terminology MUST remain consistent throughout the document.
- A concept SHOULD be introduced before terminology that depends on it.
- Examples SHOULD clarify a concept, decision or consequence.
- Sentences SHOULD carry useful information and avoid filler.
- The agent SHOULD preserve the established voice of an existing document when editing it.
- Lists SHOULD be used when items are genuinely parallel or sequential.
- Claims SHOULD be proportional to the available evidence.

## Constraints

- The agent MUST NOT use promotional or inflated language unless the document explicitly requires it.
- The agent MUST NOT repeat the same conclusion merely to add length.
- The agent MUST NOT introduce jargon without need or explanation.
- The agent MUST NOT fabricate quotations, references or attributions.
- The agent SHOULD NOT fragment prose into excessive one-sentence paragraphs.
- The agent SHOULD NOT use a table when ordinary prose is clearer.

## Validation

- Terminology is consistent.
- Paragraphs have a clear purpose and logical flow.
- Lists and tables improve comprehension rather than decorate the page.
- The document contains no unsupported quotations or invented references.
- The tone matches the target document.
