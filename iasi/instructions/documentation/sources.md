# Documentation sources

## Purpose

Keep sourced material, interpretation and original synthesis distinguishable.

## Rules

- Externally verifiable claims SHOULD be supported by appropriate sources when the document requires evidence.
- Primary sources SHOULD be preferred for technical specifications, standards, APIs and original research when practical.
- The agent MUST distinguish source claims from its own interpretation.
- Citations MUST point to sources that actually support the associated claim.
- Bibliographic conventions MUST remain consistent within a document or project.
- When a source is uncertain, incomplete or inaccessible, that limitation MUST be visible.

## Constraints

- The agent MUST NOT fabricate sources, authors, titles, dates, quotations or identifiers.
- The agent MUST NOT cite a source merely because it is topically related.
- The agent MUST NOT present paraphrase as direct quotation.
- The agent MUST NOT conceal disagreement between relevant authoritative sources.

## Validation

- Every citation supports the claim attached to it.
- Direct quotations are distinguishable from paraphrase.
- Source limitations or disagreements are visible when material.
- Bibliographic style is internally consistent.
